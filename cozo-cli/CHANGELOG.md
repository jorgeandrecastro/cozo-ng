# Changelog

Release notes for the `cozo-ng-cli` crate. Cozo-NG is an independent,
community-maintained continuation of CozoDB.

## 0.1.0

### Added

- First crates.io release of the `cozo-ng` command-line tool.
- Added query, REPL, schema, import/export, backup/restore, vector search,
  graph algorithms, remote server access, and shell completions.
